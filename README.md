# FMCW-RADAR-DESIGN-FOR-ADAPTIVE-CRUISE-CONTROL
Designed and simulated an FMCW Radar system for Adaptive Cruise Control (ACC) to detect vehicles and estimate their range and relative velocity. Implemented FMCW chirp generation, beat-frequency analysis, FFT-based range and Doppler estimation, and Range-Doppler processing for reliable automotive target detection.
